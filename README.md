# شرکت خمیر مایه خوزستان — وب‌سایت چندصفحه‌ای ری‌اکت

> **از مغز گندم؛ تا اولین برش نان**
> From the heart of wheat; to the first slice of bread

بازطراحی کامل وب‌سایت شرکت خمیر مایه خوزستان (khuzestanyeast-co.com) به‌صورت یک وب‌اپلیکیشن
چندصفحه‌ای مدرن با React، با هویت بصری **قرمز لاکی (Crimson) و سفید**، کاملاً راست‌چین (RTL) و
سرشار از انیمیشن‌های حرفه‌ای.

## ✨ ویژگی‌ها

- **چندصفحه‌ای واقعی** با React Router: خانه، درباره ما، محصولات (+ صفحه جزئیات هر محصول)،
  صادرات، کیفیت و گواهینامه‌ها، وبلاگ (+ صفحه هر مقاله)، تماس با ما و صفحه ۴۰۴
- **انیمیشن‌های فراوان و ظریف** با Framer Motion: ترنزیشن بین صفحات، Hero پارالاکس،
  نمایش پلکانی هنگام اسکرول، شمارنده‌های آماری متحرک، نوار شعار متحرک (Marquee)،
  منوی موبایل با افکت دایره‌ای، نوار پیشرفت اسکرول، افکت Ken Burns و دکمه‌های براق
- **هویت بصری Crimson/White** با تایپوگرافی فارسی **وزیرمتن** (Vazirmatn) و اعداد فارسی
- **شعار اصلی تبلیغاتی** «از مغز گندم؛ تا اولین برش نان» در Hero، نوار متحرک، بنر میانی و فوتر
- فیلتر برند‌ها (دزمایه، شتاب، ایکس پاور، نان مایه) با انیمیشن چیدمان
- فرم تماس با اعتبارسنجی و انیمیشن موفقیت
- **پنل مدیریت محتوا** در مسیر مخفی `/admin`: ویرایش متن/تصویر/پیوند همه صفحات،
  مدیریت محصولات و وبلاگ با ویرایشگر غنی (پیوند، عکس، ویدیو) و صندوق پیام‌های مردم
- **فروشگاه اینترنتی** با سبد خرید، قیمت ریالی، دیدگاه‌ها و پاسخ مدیر،
  مدیریت کامل سفارش‌ها و آماده اتصال به درگاه پرداخت ایرانی (زرین‌پال / آیدی‌پی)
- خروجی build بهینه + فایل `.htaccess` برای میزبانی SPA روی هاست‌های Apache/cPanel

## 🛠 پنل مدیریت محتوا (CMS)

نشانی پنل را **فقط با تایپ مستقیم در نوار آدرس** باز کنید — هیچ لینکی به آن در وب‌سایت وجود ندارد:

```
https://your-domain.com/admin
```

| مورد | مقدار پیش‌فرض |
| ---- | ------------- |
| نام کاربری | `admin` |
| رمز عبور | `khyeast-1404` |

> برای تغییر، متغیرهای محیطی `ADMIN_USER` و `ADMIN_PASS` و `ADMIN_SECRET` را هنگام اجرای سرور تنظیم کنید.

### امکانات پنل
- **محصولات**: ایجاد / ویرایش / حذف محصولات صفحه «محصولات» + بارگذاری تصویر + جدول مشخصات + راهنمای مصرف / آنالیز / نگهداری + انتخاب «برگزیده»
- **وبلاگ**: ایجاد / ویرایش / حذف مقالات + ویرایشگر متن غنی با **پیوند، تصویر و ویدیو** (بارگذاری فایل)
- **متون سایت**: ویرایش تک‌تک متن‌های همه صفحات (با جستجو و گروه‌بندی) — ذخیره خودکار
- **تصاویر صفحات**: جایگزینی تصویر هر بخش با بارگذاری فایل یا نشانی دلخواه
- **پیوندها**: تلفن‌ها، واتس‌اپ/تلگرام، دکمه‌های اصلی و پیوندهای داخلی
- **اطلاعات تماس**: دفترها/کارخانه‌ها (افزودن/حذف)، تلفن‌ها، نشانی‌ها، شبکه‌های اجتماعی هدر و فوتر، موضوعات فرم
- **پیام‌های مردم**: مشاهده پیام‌های فرم «ارسال پیام و استعلام قیمت»، علامت خوانده‌شده و حذف

### امنیت محتوا
مدیر محتوا تنها «مقادیر محتوا» را تغییر می‌دهد؛ استایل و کد سایت غیرقابل دست‌کاری است:
- ویرایشگر متن غنی با **پاک‌ساز سخت‌گیرانه HTML** (`src/content/sanitize.jsx`): تگ‌های `script/style/iframe`، صفت‌های `style` و `class` و رویدادها حذف می‌شوند؛ فقط ساختار متن، `a[href]` با پروتکل‌های مجاز، `img` و `video` باقی می‌ماند.
- بارگذاری فقط برای تصاویر و ویدیو مجاز است و در `/uploads/` نگهداری می‌شود.
- دسترسی پنل با توکن امضاشده (HMAC) و انقضای ۱۲ ساعته.

### اجرای سرور محتوا
پنل و ذخیره‌سازی محتوا به سرور Node نیاز دارد:

```bash
npm run server     # API + آپلودها روی پورت 8787
npm run dev        # در توسعه، ویت درخواست‌های /api و /uploads را پروکسی می‌کند
npm run build      # در تولید، همان سرور Node پوشه dist را نیز سرو می‌کند
```

## 🗄 دیتابیس

ذخیره‌سازی داده‌های زمان اجرا روی **SQLite** (کتابخانه `better-sqlite3`) انجام می‌شود؛
یک فایل تکی و تراکنشی، بدون نیاز به نصب سرویس دیتابیس جداگانه.

| محل ذخیره | داده |
| --- | --- |
| `server/data/khyeast.db` | محصولات فروشگاه، تنظیمات فروشگاه، اعتبارنامه درگاه پرداخت، سفارش‌ها و اقلام آن‌ها، دیدگاه‌ها، پیام‌های تماس |
| `server/data/content.json` | متن‌ها، تصاویر، پیوندها، برندها، محصولات کاتالوگ و مقالات وبلاگ (ویرایش تک‌کاربره از پنل) |
| `server/uploads/` | فایل‌های بارگذاری‌شده مدیر |

**جدول‌ها:** `settings`، `products`، `orders`، `order_items`، `comments`، `messages`.

**چرا SQLite:** حالت WAL و تراکنش‌ها نوشتن هم‌زمان را ایمن می‌کنند — مثلاً کسر موجودی
هنگام ثبت سفارش به‌صورت اتمیک انجام می‌شود و دو خریدار هم‌زمان نمی‌توانند بیش از موجودی
سفارش دهند. ایندکس‌ها روی `orders.at`، `orders.status`، `comments.slug` و `messages.at`
گزارش‌گیری پنل را سریع نگه می‌دارند. حذف سفارش با `ON DELETE CASCADE` اقلام آن را هم پاک می‌کند.

**مهاجرت خودکار:** در نخستین اجرا، اگر فایل‌های قدیمی `shop.json` و `messages.json` و بخش
`shop` داخل `content.json` موجود باشند، محتوایشان یک‌بار به دیتابیس منتقل می‌شود و پس از آن
دیتابیس تنها منبع حقیقت این داده‌هاست (لاگ راه‌اندازی گزارش تعداد رکوردهای منتقل‌شده را نشان می‌دهد).

**پشتیبان‌گیری:** کافی است `server/data/` و `server/uploads/` را کپی کنید. برای بکاپ گرم
می‌توانید از `sqlite3 server/data/khyeast.db ".backup backup.db"` استفاده کنید.

**مسیر دیتابیس** با متغیر محیطی `DB_FILE` قابل تغییر است.

⚠️ دیتابیس روی دیسک ماندگار نیاز دارد؛ روی سرویس‌های serverless بدون دیسک دائمی (مانند اجرای
بدون volume) داده‌ها حفظ نمی‌شوند — یک VPS یا هاست با دیسک ماندگار استفاده کنید.

## 🛒 فروشگاه اینترنتی

صفحه فروشگاه در نشانی `/shop` (از منوی اصلی و فوتر در دسترس است):

- **کارت محصولات** با قیمت ریالی، نشان تخفیف/برگزیده و وضعیت موجودی
- **صفحه محصول** با مشخصات، توضیحات غنی، پیوند به کاتالوگ فنی و محصولات مرتبط
- **سبد خرید** (`/shop/cart`) با کنترل تعداد و محاسبه ارسال رایگان
- **پرداخت** (`/shop/checkout`) با اعتبارسنجی کامل؛ مبالغ **همیشه سمت سرور** محاسبه می‌شوند
- **پیگیری سفارش** (`/shop/order/<code>`) با تایم‌لاین وضعیت و کد پیگیری خصوصی
- **دیدگاه‌ها و پرسش‌ها** زیر هر محصول + پاسخ مدیر + امکان تأیید پیش از نمایش و قفل بخش دیدگاه‌ها

### مدیریت فروشگاه از پنل (`/admin`)
| تب | کارکرد |
| --- | ------ |
| فروشگاه — محصولات | افزودن/حذف محصول، قیمت (ریال) و قیمت تخفیف، موجودی، تصویر، توضیحات غنی، جدول مشخصات، فعال/غیرفعال، **قفل دیدگاه‌های هر محصول** + تنظیمات واحد نمایش (ریال/تومان)، هزینه و سقف ارسال رایگان |
| سفارش‌ها | مشاهده اقلام/مشتری/مبالغ، تغییر وضعیت (در انتظار پرداخت ← پرداخت‌شده ← ارسال ← تحویل / لغو)، یادداشت داخلی، حذف |
| دیدگاه‌ها | تأیید/رد، **پاسخ به دیدگاه‌ها**، حذف |
| درگاه پرداخت | فعال‌سازی **زرین‌پال** یا **آیدی‌پی** با وارد کردن Merchant ID / API Key — بدون تغییر کد |

### اتصال به درگاه پرداخت ایرانی
مبالغ فروشگاه به **ریال** ذخیره و هنگام ارسال به درگاه به‌صورت خودکار به **تومان** تبدیل می‌شوند.
اعتبارنامه درگاه فقط در دیتابیس سمت سرور (`server/data/khyeast.db`، جدول `settings`) نگهداری می‌شود و هرگز در API عمومی منتشر نمی‌شود.

- **زرین‌پال**: در تب «درگاه پرداخت» Merchant ID را وارد کنید (شناسه‌های `test-*` به محیط sandbox می‌روند).
  پرداخت از `api.zarinpal.com/pg/v4` و بازگشت از `/api/shop-pay/zarinpal/callback` انجام می‌شود.
- **آیدی‌پی**: API Key را وارد کنید و در صورت نیاز حالت Sandbox را فعال نگه دارید.
- تا فعال‌نشدن درگاه، سفارش‌ها با وضعیت «در انتظار پرداخت» ثبت و از پنل مدیریت می‌شوند.
- اگر سایت پشت پروکسی/دامنه دیگری است، «نشانی پایه بازگشت از درگاه» را روی دامنه نهایی تنظیم کنید.

## 🖼 درباره تصاویر محصولات

تصاویر بسته‌بندی، رندرهای استودیویی با لیبل‌های طراحی‌شده برند (نشان گندم + پالت
Crimson/White) هستند که با اسکریپت `scripts/rebrand-packs.mjs` یکدست‌سازی شده‌اند. برای جایگزینی با عکس‌های واقعی محصولات، کافی است فایل‌های هم‌نام در
`public/assets/products/` را جایگزین کنید.

##  استقرار

خروجی `dist/` را روی هر میزبان استاتیک یا هاست اشتراکی قرار دهید؛ فایل `.htaccess` داخل
پوشه `public/` به‌صورت خودکار کپی شده و مسیریابی SPA را روی Apache فعال می‌کند.
