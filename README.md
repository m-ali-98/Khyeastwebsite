# شرکت خمیر مایه خوزستان — وب‌سایت چندصفحه‌ای ری‌اکت

> **از مغز گندم؛ تا اولین برش نان**
> From the heart of wheat; to the first slice of bread

بازطراحی کامل وب‌سایت شرکت خمیر مایه خوزستان (khuzestanyeast-co.com) به‌صورت یک وب‌اپلیکیشن
چندصفحه‌ای مدرن با React، با هویت بصری **قرمز لاکی (Crimson) و سفید**، کاملاً راست‌چین (RTL) و
سرشار از انیمیشن‌های حرفه‌ای.

## ✨ ویژگی‌ها

- **چندصفحه‌ای واقعی** با React Router: خانه، درباره ما، محصولات (+ صفحه جزئیات هر محصول)،
  صادرات، کیفیت و گواهینامه‌ها، وبلاگ (+ صفحه هر مقاله)، تماس با ما و صفحه ۴۰۴
- **انیمیشن‌های فراوان و ظریف** با Framer Motion: ترنزیشن بین صفحات، Hero پارالاکس،
  نمایش پلکانی هنگام اسکرول، شمارنده‌های آماری متحرک، نوار شعار متحرک (Marquee)،
  منوی موبایل با افکت دایره‌ای، نوار پیشرفت اسکرول، افکت Ken Burns و دکمه‌های براق
- **هویت بصری Crimson/White** با تایپوگرافی فارسی **وزیرمتن** (Vazirmatn) و اعداد فارسی
- **شعار اصلی تبلیغاتی** «از مغز گندم؛ تا اولین برش نان» در Hero، نوار متحرک، بنر میانی و فوتر
- فیلتر برند‌ها (دزمایه، شتاب، ایکس پاور، نان مایه) با انیمیشن چیدمان
- فرم تماس با اعتبارسنجی و انیمیشن موفقیت
- خروجی build بهینه + فایل `.htaccess` برای میزبانی SPA روی هاست‌های Apache/cPanel

## 🧰 تکنولوژی‌ها

| لایه      | انتخاب                              |
| --------- | ----------------------------------- |
| فریم‌ورک  | React 19 + Vite 8                   |
| مسیریابی  | React Router 7                      |
| انیمیشن   | Framer Motion                       |
| استایل    | SCSS (طراحی سیستم اختصاصی RTL)      |
| فونت      | Vazirmatn (Fontsource، آفلاین)      |
| تصاویر    | تولید/پردازش داخلی (بخش Assets)      |

## 🚀 اجرا و توسعه

```bash
npm install
npm run dev        # سرور توسعه → http://localhost:5173
npm run build      # خروجی تولید در پوشه dist
npm run preview    # پیش‌نمایش خروجی تولید
```

## 🗂 ساختار پروژه

```
├── index.html               # قالب RTL فارسی + متا تگ‌های SEO
├── public/
│   ├── .htaccess            # بازنویسی SPA برای Apache
│   ├── favicon.svg
│   └── assets/              # تصاویر برند، محصولات و مقالات
├── scripts/
│   └── rebrand-packs.mjs    # اسکریپت یکپارچه‌سازی لیبل بسته‌بندی‌ها (sharp)
└── src/
    ├── main.jsx / App.jsx   # ورودی + مسیریابی و ترنزیشن صفحات
    ├── styles/global.scss   # سیستم طراحی (رنگ، تایپوگرافی، کامپوننت‌ها)
    ├── data/                # محتوای فارسی: شرکت، محصولات، مقالات
    ├── components/          # Navbar، Footer، Logo، کارت‌ها، اجزای انیمیشنی
    └── pages/               # ۹ صفحه اصلی + ۴۰۴
```

## 🛠 پنل مدیریت محتوا (CMS)

نشانی پنل را **فقط با تایپ مستقیم در نوار آدرس** باز کنید — هیچ لینکی به آن در وب‌سایت وجود ندارد:

```
https://your-domain.com/admin
```

| مورد | مقدار پیش‌فرض |
| ---- | ------------- |
| نام کاربری | `admin` |
| رمز عبور | `khyeast-1404` |

> برای تغییر، متغیرهای محیطی `ADMIN_USER` و `ADMIN_PASS` و `ADMIN_SECRET` را هنگام اجرای سرور تنظیم کنید.

### امکانات پنل
- **محصولات**: ایجاد / ویرایش / حذف محصولات صفحه «محصولات» + بارگذاری تصویر + جدول مشخصات + راهنمای مصرف / آنالیز / نگهداری + انتخاب «برگزیده»
- **وبلاگ**: ایجاد / ویرایش / حذف مقالات + ویرایشگر متن غنی با **پیوند، تصویر و ویدیو** (بارگذاری فایل)
- **متون سایت**: ویرایش تک‌تک متن‌های همه صفحات (با جستجو و گروه‌بندی) — ذخیره خودکار
- **تصاویر صفحات**: جایگزینی تصویر هر بخش با بارگذاری فایل یا نشانی دلخواه
- **پیوندها**: تلفن‌ها، واتس‌اپ/تلگرام، دکمه‌های اصلی و پیوندهای داخلی
- **اطلاعات تماس**: دفترها/کارخانه‌ها (افزودن/حذف)، تلفن‌ها، نشانی‌ها، شبکه‌های اجتماعی هدر و فوتر، موضوعات فرم
- **پیام‌های مردم**: مشاهده پیام‌های فرم «ارسال پیام و استعلام قیمت»، علامت خوانده‌شده و حذف

### امنیت محتوا
مدیر محتوا تنها «مقادیر محتوا» را تغییر می‌دهد؛ استایل و کد سایت غیرقابل دست‌کاری است:
- ویرایشگر متن غنی با **پاک‌ساز سخت‌گیرانه HTML** (`src/content/sanitize.jsx`): تگ‌های `script/style/iframe`، صفت‌های `style` و `class` و رویدادها حذف می‌شوند؛ فقط ساختار متن، `a[href]` با پروتکل‌های مجاز، `img` و `video` باقی می‌ماند.
- بارگذاری فقط برای تصاویر و ویدیو مجاز است و در `/uploads/` نگهداری می‌شود.
- دسترسی پنل با توکن امضاشده (HMAC) و انقضای ۱۲ ساعته.

### اجرای سرور محتوا
پنل و ذخیره‌سازی محتوا به سرور Node نیاز دارد:

```bash
npm run server     # API + آپلودها روی پورت 8787
npm run dev        # در توسعه، ویت درخواست‌های /api و /uploads را پروکسی می‌کند
npm run build      # در تولید، همان سرور Node پوشه dist را نیز سرو می‌کند
```

داده‌ها در `server/data/content.json` و `server/data/messages.json` و فایل‌های بارگذاری‌شده در
`server/uploads/` ذخیره می‌شوند.

## 🖼 درباره تصاویر محصولات

تصاویر بسته‌بندی، رندرهای استودیویی با لیبل‌های طراحی‌شده برند (نشان گندم + پالت
Crimson/White) هستند که با اسکریپت `scripts/rebrand-packs.mjs` یکدست‌سازی شده‌اند. برای جایگزینی با عکس‌های واقعی محصولات، کافی است فایل‌های هم‌نام در
`public/assets/products/` را جایگزین کنید.

##  استقرار

خروجی `dist/` را روی هر میزبان استاتیک یا هاست اشتراکی قرار دهید؛ فایل `.htaccess` داخل
پوشه `public/` به‌صورت خودکار کپی شده و مسیریابی SPA را روی Apache فعال می‌کند.
