# تصاویر اصلی (originals)

فایل‌های این پوشه **روی سایت آپلود نمی‌شوند**.

نسخهٔ اصلی و بدون فشرده‌سازی تصاویر اینجا نگهداری می‌شود. چیزی که سایت واقعاً
استفاده می‌کند نسخهٔ `.webp` همین تصاویر است که در `public/assets/` قرار دارد.

چرا جدا شده‌اند؟ این ۹ فایل روی هم حدود **۵٫۴ مگابایت** هستند و هیچ‌کجای سایت
به آن‌ها ارجاعی وجود ندارد — ولی چون داخل `public/` بودند، در هر بار ساخت
(build) کپی می‌شدند و باید در هر بار آپلود روی هاست منتقل می‌شدند. خروجی build
با این تغییر از ۷٫۷ مگابایت به حدود ۲٫۳ مگابایت رسید.

نگهداری‌شان لازم است: اگر روزی خواستید تصویر را دوباره برش بزنید یا با کیفیت
دیگری خروجی بگیرید، باید از روی همین نسخهٔ اصلی این کار را بکنید، نه از روی
`.webp` (فشرده‌سازی دوباره روی یک فایل فشرده، کیفیت را خراب می‌کند).

## ساخت دوبارهٔ نسخهٔ webp

    node scripts/to-webp.mjs

نتیجه در `public/assets/` نوشته می‌شود.
